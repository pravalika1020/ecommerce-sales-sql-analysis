# E-Commerce Sales Analysis using SQL

## Project Overview

This project analyzes e-commerce sales data using MySQL.

The project uses relational database tables for products and orders and applies SQL queries to generate useful business insights such as total revenue, top-selling products, category revenue, average order value, and total items sold.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench
- RDBMS

## Database Structure

### Products Table

Contains:

- Product ID
- Product Name
- Category
- Price

### Orders Table

Contains:

- Order ID
- Product ID
- Quantity
- Order Date

## Analysis Performed

The project includes SQL queries for:

1. Revenue generated by each product
2. Total revenue
3. Top-selling product
4. Revenue by category
5. Average order value
6. Total items sold

## Key Learning

This project provides hands-on experience with relational databases and SQL-based data analysis. It demonstrates how structured sales data can be queried to generate business insights.

## How to Run

1. Open MySQL Workbench.
2. Create/select the `ecommerce_sales` database.
3. Run the SQL script.
4. Execute the analysis queries.
5. Review the results in MySQL Workbench.
